Task Tracker CLI
Aplicação de linha de comando desenvolvida em Python para cadastrar, atualizar, excluir e acompanhar tarefas.

Status
Projeto em desenvolvimento.

Objetivos
Praticar manipulação de arquivos JSON.
Processar argumentos da linha de comando.
Desenvolver uma aplicação CLI.
Praticar versionamento com Git.
Restrições
Utilizar somente recursos nativos do Python.
Armazenar as tarefas em um arquivo JSON.
Não utilizar frameworks ou bibliotecas externas.
